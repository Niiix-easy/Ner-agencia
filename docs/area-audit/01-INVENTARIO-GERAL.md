## 3. Resumo Estrutural do Repositório Auditado

- **Frontend:** React 19 + TypeScript + Vite 8 + Tailwind CSS + Recharts 3 (`src/App.tsx` + 9 arquivos em `src/components/`).
- **Backend:** Express 4 + TypeScript (`server.ts` -> `server/app.ts` [2.097 linhas] + `server/ai/*` [8 módulos] + `server/services/*` [2 serviços] + `server/middleware/auth.ts`).
- **Persistência em Runtime:** `PersistentStore` (`server/store.ts`) gravando atomicamente em `database/data/ner-db.json` (`.tmp` + `renameSync`).
- **Arquivos de Banco Relacional em Disco (NÃO ativos no runtime):** `database/schema/schema.prisma` (617 linhas), 2 migrations SQL em `database/migrations/`, `docker-compose.yml` (Postgres 16, Redis 7, MinIO, n8n).
- **Testes Automatizados:** 4 arquivos em `tests/` totalizando **28 testes** executados via `tsx --test tests/*.test.ts`.
